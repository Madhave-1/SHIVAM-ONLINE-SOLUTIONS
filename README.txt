SHIVAM ONLINE SOLUTIONS - GitHub Pages starter

BEFORE PUBLISHING:
1. Replace REPLACE_WITH_BUSINESS_EMAIL, REPLACE_WITH_BUSINESS_PHONE and REPLACE_WITH_PUBLIC_BUSINESS_ADDRESS in index.html.
2. Replace [Add publication date] and [Add the business email address] in privacy.html.
3. Confirm the proprietor approves every business detail displayed publicly.
4. Review the Privacy Policy and update it if the site later uses forms, analytics, cookies or third-party services.

PUBLISH:
1. Create a PUBLIC GitHub repository named exactly: YOUR-GITHUB-USERNAME.github.io
2. Upload index.html, privacy.html, styles.css, script.js and README.txt to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. The site URL will be https://YOUR-GITHUB-USERNAME.github.io/

GOOGLE PLAY:
A live GitHub Pages site is not a guarantee of Google Play acceptance as an official organization website. The site must accurately represent the business. Google Play requires the website URL to be entered and verified in Play Console before the account-type conversion option is enabled. Follow the current Play Console verification flow and do not claim the site is verified until Google confirms it.
